 Max Heap Sort:

Definition:
Max Heap Sort is a sorting algorithm that uses a **max heap** data structure. It first builds a max heap, where the largest element is at the root, and then repeatedly removes the largest element and places it at the end of the array.

 Time Complexity:** O(n log n) in best, average, and worst cases.

 Conclusion:
Max Heap Sort is an efficient and reliable sorting algorithm with O(n log n) time complexity in all cases. It sorts the elements in-place and requires very little extra memory. However, it is generally more complex to implement than simple sorting algorithms such as Bubble Sort and Insertion Sort.
